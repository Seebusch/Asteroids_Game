# Asteroids Game v1.0.0

Erster dokumentierter Release des spielbaren Pygame-Asteroids-Spiels.

## Enthalten

- Raumschiffsteuerung, Laser und Asteroiden in drei Größen mit Teilungsmechanik.
- Punktestand und aufeinanderfolgende, zunehmend schwierigere Level.
- Pause, Neustart nach Game Over, anpassbare Fenstergröße und Vollbild.
- Sprites, Weltraumhintergrund und Lasersound.
- README mit Installation und Steuerung; Roadmap für geplante Boni.

## Installation

Python 3 und Pygame werden benötigt. Im Repository-Verzeichnis:

```bash
python -m venv .venv
# Virtuelle Umgebung aktivieren (siehe README)
python -m pip install -r requirements.txt
python -m asteroids
```

Bomben und Multishot / Splitshot sind für spätere Versionen geplant und in diesem Release noch nicht enthalten.
